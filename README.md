# Native Instagram 📸

A modern Instagram-like social media application built using **Firebase (BaaS)**, focusing on real-time interaction, authentication, and scalable backend services.

This project demonstrates hands-on experience in building **mobile applications**, integrating **cloud-based backend services**, and managing **real-time data** efficiently.

---

## 🚀 Features

- User authentication (Sign up / Login)
- Create and upload posts with images
- Real-time feed updates
- Like and interact with posts
- User profile management
- Secure cloud data storage
- Scalable backend using Firebase services

---

## 🛠 Tech Stack

**Frontend / Mobile**
- React Native
- JavaScript

**Backend (BaaS)**
- Firebase Authentication
- Firebase Firestore (Database)
- Firebase Storage
- Firebase Cloud Services

---

## 📱 App Highlights

- Real-time data synchronization using Firestore
- Secure authentication and user session handling
